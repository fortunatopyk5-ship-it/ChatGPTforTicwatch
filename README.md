# WristGPT Bridge for TicWatch Pro 5

Experimental Wear OS app with a circular keyboard-first interface. It does NOT use the OpenAI API. It requires the original, unmodified ChatGPT Android app to be separately installed and signed in on the watch, if compatible. Accessibility-based UI automation is not guaranteed to work.

Builds an APK using GitHub Actions; no Android Studio required locally. No login credentials are requested or stored in WristGPT Bridge.

**Warning:** Prototype, not an official OpenAI app. ChatGPT for Android is not confirmed to support Wear OS or Google sign-in on watches.
